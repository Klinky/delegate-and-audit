# Bundled OpenAI model references

Read only the document matching the orchestrator or a worker model in use. Filenames use exact model IDs. Do not load this collection wholesale or follow its online links for routine cutoff discovery.

These are verbatim official Markdown snapshots. [manifest.json](manifest.json) records source URLs, UTC retrieval times, cutoff text, and SHA-256 hashes. Root-relative links inside downloaded documents refer to https://developers.openai.com, not the local filesystem. Those links are not dependencies for cutoff lookup.

Coverage: current Codex model choices and recent general-purpose, coding, and reasoning models, including common smaller and older alternatives. This is not a measured popularity ranking, a complete historical catalog, or a claim of availability. Specialized image, audio, embedding, and moderation models are outside this agent-focused bundle.

Refresh only during explicit skill maintenance; do not auto-refresh during orchestration. Saved aliases may change upstream. Use the exact alias/snapshot rules in [the lookup procedure](../model-cutoff.md).
